자격·면허 갱신 & 보수교육 트래커

갱신 기한과 보수교육 학점,
놓치기 전에 보이게

여러 개의 자격을 가진 분을 위해 만들었습니다. 만료일과 주기, 이수 학점을 기록하면 남은 기간과 필요한 페이스를 계산하고, 달력에 넣을 알림 파일을 만들어 드립니다. 데이터는 이 브라우저에만 저장됩니다.

내 자격 등록하기 어떻게 쓰나요?

예시 템플릿의 주기와 시간은 참고용입니다. 반드시 발급 기관과 최신 법령에서 확인하세요.

기한을 놓치면 벌금, 면허 정지, 소득 손실이 생깁니다

흩어진 수료증과 달력 메모 대신, 하나의 기록과 하나의 화면으로 관리하세요.

만료일과 갱신 주기

만료일을 직접 입력하거나 발급일과 주기(년)만 넣으면 됩니다. 주기 기간과 다음 마감을 자동으로 계산합니다.

학점 페이스와 예상 부족

이수 진행률, 남은 기간의 월 필요량, 지금 속도로 가면 얼마나 부족할지 보여 줍니다.

달력 알림 파일

180·90·30·7일 전 알림을 담은 .ics 파일을 받아 휴대폰이나 PC 달력에 넣을 수 있습니다.

백업, CSV, 인쇄

JSON 백업으로 기기를 옮기고, 학점 기록은 CSV로 내보내며, 요약표는 인쇄하거나 PDF로 저장합니다.

사용 순서 3단계

  1. 1

    자격 등록

    예시 템플릿을 고른 뒤 자격명, 발급 기관, 만료일 또는 주기, 필요 학점을 입력합니다.

  2. 2

    이수 기록

    교육을 들을 때마다 날짜, 시간, 과정명과 인증서 메모를 남깁니다.

  3. 3

    알림 설정

    알림 기간을 정하고 .ics 파일을 달력 앱에 가져옵니다. 앱을 열면 기한 임박 항목을 상단에 알려 줍니다.

내 자격 관리

모든 데이터는 이 브라우저의 저장소에만 있습니다. 기기를 옮기기 전에 JSON 백업을 받아 두세요.

                    달력 파일 (.ics)

                    각 마감일마다 종일 일정이 만들어지고, 설정한 기간마다 알림(VALARM)이 붙습니다. 달력 앱에서 파일을 가져오면 됩니다.

                    • 자격 번호는 파일에 넣지 않습니다.
                    • 항목을 바꾼 뒤에는 파일을 다시 받아 가져오세요. 같은 항목·마감일은 같은 식별자를 가집니다.
                    • 알림이 울리는 시각은 달력 앱 설정에 따릅니다. 앱에 따라 종일 일정 알림이 다르게 동작할 수 있습니다.

                    브라우저 알림 (앱을 열었을 때)

                    앱을 열면 알림 기간 안에 든 항목을 한 번씩 브라우저 알림으로 보여 줍니다. 서버가 없어서 앱이 닫혀 있으면 알림이 오지 않습니다.

                    자격, 학점 기록, 알림 설정을 한 파일로 저장합니다. 불러오면 현재 데이터를 모두 바꿉니다.

                    참고용 계산 결과이며 법률, 세무, 재무 자문이 아닙니다.

                    이 브라우저에 저장된 모든 자격과 학점 기록을 지웁니다. 되돌릴 수 없으니 먼저 백업을 받으세요.

                    AI 보수교육 계획 (선택 기능)

                    남은 학점을 월별로 나눈 계획을 만듭니다. 사용하지 않아도 앱의 모든 기능이 동작합니다.

                    브라우저에 저장한 API 키는 개발자도구에서 볼 수 있습니다. 공용 컴퓨터에서는 저장하지 마세요.

                    AI 기능으로 보내는 내용
                    • 익명 기호(A1, A2…), 남은 학점, 남은 개월 수
                    • 분류 이름과 분류별 이수 학점 숫자
                    • 보내지 않는 것: 자격명, 발급 기관, 자격 번호, 메모, 과정명, 제공 기관, 날짜

                    마감이 12개월 넘게 남았거나 항목이 8개를 넘으면 AI 대신 로컬 계획을 씁니다. 버튼을 누를 때만 전송합니다.

                    로컬 계획 방식

                    계획은 참고용 제안입니다. 실제 이수 가능 여부와 과정 선택은 본인이 확인하세요.

                    자주 묻는 질문

                    데이터는 어디에 저장되나요?

                    이 브라우저의 로컬 저장소(localStorage)에만 저장합니다. 서버로 보내지 않습니다. 브라우저 데이터를 지우거나 다른 기기를 쓰면 보이지 않으니 JSON 백업을 받아 두세요.

                    템플릿의 주기와 시간은 맞나요?

                    모두 예시 값입니다. 템플릿은 입력 칸을 채우는 용도일 뿐이며, 실제 주기와 이수 시간은 발급 기관과 최신 법령에서 확인해 직접 고쳐 쓰세요.

                    알림이 자동으로 울리나요?

                    이 앱은 서버가 없어서 스스로 알림을 보내지 못합니다. .ics 파일을 달력 앱에 가져와야 알림이 등록됩니다. 앱을 열면 기한 임박 항목을 상단에 표시합니다.

                    학점은 어떤 기간을 기준으로 세나요?

                    만료일을 주기 종료일로 보고, 종료일 − 주기(년) + 1일부터 종료일까지 기록한 학점을 이번 주기로 집계합니다. 기간 밖 기록은 따로 표시하며 합계에 넣지 않습니다. 이월 학점은 직접 입력합니다.

                    AI 기능은 꼭 써야 하나요?

                    아닙니다. 로컬 계획은 API 키 없이 동작합니다. AI 기능을 쓰려면 본인 Anthropic API 키를 직접 넣어야 하며, 이때 위에 적힌 최소한의 숫자 정보만 보냅니다.
