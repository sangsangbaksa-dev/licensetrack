자격·면허 갱신과 보수교육 트래커

갱신 기한과 학점을 한 장의 화면으로

자격마다 만료일이나 주기, 필요 학점을 적어 두면 남은 기간과 이수 진행률, 앞으로 울릴 알림을 한 번에 봅니다. 가족 자격은 보유자별로 나눠 봅니다. 데이터는 이 브라우저에만 저장됩니다.

  • 계정·서버 없음
  • 달력(.ics) 알림 파일
  • JSON 백업·CSV 가져오기

화면의 자격명과 학점은 예시 데이터입니다. 템플릿의 주기와 시간은 예시 · 확인 필요입니다.

화면은 네 가지로 나뉩니다

대시보드에서 전체를 보고, 자격 탭에서 등록하고, 학점 탭에서 기록하고, 알림·달력 탭에서 시점을 정합니다. 각 화면은 같은 데이터를 다른 방식으로 보여 줍니다.

대시보드

만료, 30일 이내, 90일 이내, 여유 순으로 정렬하고, 보유자별로 묶어 볼 수 있습니다.

학점 기록과 페이스

주기 기간 안의 기록만 합산합니다. 지금 속도로 가면 부족할지, 남은 기간에 매달 얼마가 필요한지 보여 줍니다.

연간 달력

하루 단위로 학점 기록의 양과 마감일을 한 해 전체에 펼쳐 봅니다. 해를 넘겨 가며 볼 수 있습니다.

알림 기간과 달력 파일

표준·짧게·길게 프리셋 중 고르거나 직접 입력합니다. 앞으로 울릴 날짜를 목록으로 보여 주고, .ics 파일로 내보냅니다.

템플릿과 중복 확인

예시 템플릿의 주기와 필요 학점은 직접 고칠 수 있습니다. 이름이나 자격 번호가 같은 항목은 저장 전에 알려 줍니다.

백업·CSV·인쇄

JSON 백업으로 기기를 옮기고, 학점 기록은 CSV로 내보내거나 가져옵니다. 가져올 때 틀린 행은 행 번호와 이유를 보여 줍니다.

기한을 흩어 두지 않도록

수료증 봉투와 달력 메모 대신, 하나의 기록과 하나의 화면으로 관리합니다.

만료일 또는 주기
만료일을 직접 적거나 발급일과 주기(년)만 넣으면 됩니다. 주기 기간과 다음 마감을 계산합니다. 발급일과 주기로 만든 만료일은 기념일 전날로 봅니다.
보유자별로 나누기
가족 자격을 한 앱에 넣을 때 보유자 이름을 붙이면 보유자별 요약과 필터를 씁니다. 이름은 달력 파일과 AI 기능에 들어가지 않습니다.
기록은 한 줄씩 확인
CSV를 가져오면 자격명이 맞지 않거나 날짜가 틀린 행을 행 번호와 함께 보여 줍니다. 정상 행만 추가하고, 이미 있는 기록은 건너뜁니다.

사용 순서 4단계

처음에는 자격 하나만 넣어 보세요. 나머지는 같은 방식으로 이어서 넣으면 됩니다.

  1. 자격 등록

    예시 템플릿을 고르거나 직접 입력합니다. 만료일 또는 발급일과 주기, 필요 학점을 적습니다.

  2. 이수 기록

    교육을 받을 때마다 날짜와 시간, 과정명을 남깁니다. 여러 건이면 CSV로 한 번에 가져올 수 있습니다.

  3. 알림 정하기

    알림 프리셋을 고르고, 앞으로 울릴 날짜 목록을 확인합니다. 달력 앱에 .ics 파일을 가져오면 같은 날짜에 알림이 울립니다.

  4. 주기적으로 백업

    JSON 백업을 받아 두면 기기를 바꾸거나 브라우저 데이터를 지워도 되돌릴 수 있습니다.

데이터와 계산에 대해

저장 위치
자격과 학점 기록은 이 브라우저의 저장소에만 있습니다. 서버 계정이나 업로드 기능이 없습니다. 브라우저 데이터를 지우면 함께 사라지니 백업을 받아 두세요.
AI 계획은 선택
본인 API 키를 직접 넣고 버튼을 눌렀을 때만 남은 학점의 숫자 요약을 보냅니다. 키가 없어도 로컬 계획으로 같은 기능을 씁니다.
예시 값과 확인
템플릿의 주기와 필요 학점은 예시 · 확인 필요 값입니다. 법령이나 기관 기준이 아니므로 발급 기관에서 확인해 직접 고쳐 쓰세요.

내 자격 관리

모든 데이터는 이 브라우저의 저장소에만 있습니다. 기기를 옮기기 전에 JSON 백업을 받아 두세요.

              등록된 자격

                이수 기록 추가

                기록 목록

                  아직 기록이 없습니다.

                  학점 기록 CSV 가져오기

                  내보내기로 받은 CSV(자격명, 날짜, 이수시간, 과정명, 제공기관, 분류, 메모)를 읽습니다. 자격명은 등록된 이름과 정확히 같아야 합니다. 잘못된 행은 건너뛰고 행 번호와 이유를 보여 줍니다.

                  알림 기간

                  프리셋 (누르면 바로 저장)

                  1~730 사이 정수, 최대 8개. 기본값은 180, 90, 30, 7 입니다.

                  곧 울릴 알림 (앱 기준 예정)

                    앞으로 울릴 알림이 없습니다. 자격을 등록하거나 알림 기간을 바꿔 보세요.

                    달력 파일 (.ics)

                    각 마감일마다 종일 일정이 만들어지고, 설정한 기간마다 알림(VALARM)이 붙습니다. 달력 앱에서 파일을 가져오면 됩니다.

                    • 자격 번호는 파일에 넣지 않습니다. 보유자 이름도 넣지 않습니다.
                    • 항목을 바꾼 뒤에는 파일을 다시 받아 가져오세요. 같은 항목·마감일은 같은 식별자를 가집니다.
                    • 알림이 울리는 시각은 달력 앱 설정에 따릅니다. 앱에 따라 종일 일정 알림이 다르게 동작할 수 있습니다.

                    브라우저 알림 (앱을 열었을 때)

                    앱을 열면 알림 기간 안에 든 항목을 한 번씩 브라우저 알림으로 보여 줍니다. 서버가 없어서 앱이 닫혀 있으면 알림이 오지 않습니다.

                    JSON 백업

                    자격, 학점 기록, 알림 설정, 템플릿 수정값을 한 파일로 저장합니다. 불러오면 현재 데이터를 모두 바꿉니다.

                    요약 인쇄

                    자격별 마감일, 필요 학점, 이수 학점을 한 장으로 정리합니다.

                    자격·면허 갱신·보수교육 요약

                    자격명발급 기관만료일남은 기간주기 시작필요이수상태

                    자격별 이수 내역 (이번 주기)

                    참고용 계산 결과이며 법률, 세무, 재무 자문이 아닙니다. 자격 번호와 메모는 인쇄하지 않습니다.

                    데이터 삭제

                    이 브라우저에 저장된 모든 자격과 학점 기록을 지웁니다. 되돌릴 수 없으니 먼저 백업을 받으세요.

                    AI 보수교육 계획 (선택 기능)

                    남은 학점을 월별로 나눈 계획을 만듭니다. 사용하지 않아도 앱의 모든 기능이 동작합니다.

                    브라우저에 저장한 API 키는 개발자도구에서 볼 수 있습니다. 공용 컴퓨터에서는 저장하지 마세요.

                    AI 기능으로 보내는 내용
                    • 익명 기호(A1, A2…), 남은 학점, 남은 개월 수

                    • 보내지 않는 것: 자격명, 발급 기관, 자격 번호, 보유자, 메모, 과정명, 제공 기관, 날짜

                    자주 묻는 질문
                    
        
                    
          
                    데이터는 어디에 저장되나요?
                    이 브라우저의 로컬 저장소(localStorage)에만 저장합니다. 서버로 보내지 않습니다. 브라우저 데이터를 지우거나 다른 기기를 쓰면 보이지 않으니 JSON 백업을 받아 두세요.
                    
          
                    템플릿의 주기와 시간은 맞나요?
                    모두 예시 · 확인 필요 값입니다. 템플릿은 입력 칸을 채우는 출발점이며, 자격 탭의 편집 칸에서 주기와 필요 학점을 바꿀 수 있습니다. 실제 값은 발급 기관과 최신 법령에서 확인하세요.
                    
          
                    알림이 자동으로 울리나요?
                    이 앱은 서버가 없어서 스스로 알림을 보내지 못합니다. .ics 파일을 달력 앱에 가져와야 알림이 등록됩니다. 앱을 열면 기한 임박 항목을 상단에 표시합니다.
                    
          
                    가족 자격을 한 앱에서 나눠 볼 수 있나요?
                    자격마다 보유자 이름을 적으면 대시보드에서 보유자별로 보고, 보유자별 요약 카드를 눌러 거를 수 있습니다. 보유자 이름은 달력 파일과 AI 기능으로 보내지 않습니다.
                    
          
                    학점은 어떤 기간을 기준으로 세나요?
                    만료일을 주기 종료일로 보고, 종료일 − 주기(년) + 1일부터 종료일까지 기록한 학점을 이번 주기로 집계합니다. 기간 밖 기록은 따로 표시하며 합계에 넣지 않습니다. 이월 학점은 직접 입력합니다.
                    
          
                    CSV를 가져오다 오류가 나면 어떻게 하나요?
                    오류가 난 행만 건너뛰고 나머지 정상 행은 추가합니다. 행 번호와 이유를 보여 주므로 그 행을 고쳐서 다시 가져오세요. 자격명이 같은 자격이 두 개 있으면 그 행은 가져오지 않습니다.
                    
          
                    AI 기능은 꼭 써야 하나요?
                    아닙니다. 로컬 계획은 API 키 없이 동작합니다. AI 기능을 쓰려면 본인 Anthropic API 키를 직접 넣어야 하며, 이때 위에 적힌 최소한의 숫자 정보만 보냅니다.
