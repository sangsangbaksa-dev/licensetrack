# licensetrack · 자격·면허 갱신 & 보수교육 트래커

자격증·면허의 **만료일(또는 갱신 주기)** 과 **보수교육 학점**을 한 화면에서 관리하는 정적 웹 앱입니다.
서버가 없고, 빌드 과정도 없습니다. HTML, CSS, ES 모듈과 localStorage만 사용합니다.

## 주요 기능

1. **자격 항목**: 자격명, 발급 기관, 자격 번호(선택), 발급일, 만료일 또는 발급일 + 갱신 주기(년), 주기당 필요 학점, 이월 학점, 메모.
   예시 템플릿 8종(간호사, 공인중개사, 안전관리자, 사회복지사, 세무·회계 CPE, 건설기술인, 위험물 안전관리자 등)은 **모두 예시 값**이며 폼에 채워 넣는 용도입니다. 채운 뒤 수정해서 씁니다.
2. **학점 기록**: 이수일, 시간(학점), 과정명, 제공 기관, 분류, 인증서 메모. 주기별 진행률, 예상 부족, 남은 기간 월 필요량, 이전·다음 주기 기록 구분을 보여 줍니다.
3. **대시보드**: 만료 / 30일 이내 / 90일 이내 / 여유 / 만료일 없음 순으로 정렬, 상태별 개수, 365일 타임라인.
4. **알림**: 기본 180·90·30·7일 전(설정 변경 가능). 앱을 열면 알림 기간 안의 항목을 상단에 표시하고, 브라우저 알림 권한을 허용하면 한 번씩 알림을 보냅니다. **달력 파일(.ics)** 에는 각 마감일마다 종일 일정과 기간별 VALARM을 넣습니다.
5. **백업·복원**: JSON 백업 저장과 불러오기(검증 후 적용, 실패 시 현재 데이터 유지), 학점 기록 CSV(수식 주입 방지, BOM 포함), 요약 인쇄(`window.print`).
6. **AI 계획 (선택)**: 남은 학점을 월별로 나눈 계획. 자세한 내용은 아래 AI 섹션.

## 계산 규칙과 기준

모든 상수와 규칙 문장은 `logic.js` 상단 `CONSTANTS` 에 있고, 화면의 "계산 규칙과 기준" 에도 같은 문장이 나옵니다.

| 항목 | 규칙 | 출처·기준 |
|---|---|---|
| 날짜 형식 | 모든 날짜는 로컬 `YYYY-MM-DD` 문자열. 일 수 계산은 UTC 일수로 해서 시간대 영향이 없음 | 앱 내부 규칙 |
| 말일 보정 | 2월 29일 + 1년 = **2월 28일**, 1월 31일 + 1개월 = 2월 말일 | 앱 내부 규칙 (선택 기준: 말일 보정) |
| 주기 기간 | 종료일 = 만료일, 시작일 = 만료일 − 주기(년) + 1일 | 앱 내부 규칙 |
| 파생 만료일 | 만료일이 없으면 발급일 + 주기(년) − 1일 (기념일 전날) | 앱 내부 규칙 |
| 학점 집계 | 주기 기간 안의 기록만 합산. 이전 주기 기록은 별도 표시, 다음 주기 기록은 제외 | 앱 내부 규칙 |
| 이월 학점 | 사용자가 직접 입력한 값을 합계에 더함. 이월 가능 한도는 **계산하지 않음** | 기관 규정 확인 필요 |
| 긴급도 | 만료일 당일 = 30일 이내. 0~30일 남음 = 30일 이내, 31~90일 = 90일 이내 (30·90일 경계 포함), 91일 이상 = 여유 | `urgency.soonDays = 30`, `warnDays = 90` |
| 월 페이스 | 주기 시작 이후 이수 학점 ÷ 경과 개월 (최소 1개월) | 앱 내부 규칙 |
| 예상 부족 | 필요 − (현재 합계 + 월 페이스 × 남은 개월), 0 미만은 0 | 앱 내부 규칙 |
| 월 필요량 | 남은 학점 ÷ 남은 개월 (남은 기간이 1개월 미만이면 1개월) | 앱 내부 규칙 |
| 알림 기간 | 기본 `[180, 90, 30, 7]`일 전, 1~730 정수, 최대 8개 | 사용자 설정 |

기준일 라벨: **앱 작성 시점 2026-11**. 법령 수치가 아니라 앱의 계산 규칙입니다.
템플릿 값(주기, 필요 시간)은 **법령·기관 기준이 아니며 확인되지 않은 예시**입니다.

## 실행 방법

```bash
cd licensetrack
python3 -m http.server 8131      # 파일 열기(file://)는 ES 모듈이 막히므로 서버로 실행
# 브라우저에서 http://127.0.0.1:8131/index.html
```

## 테스트

```bash
node --test tests/logic.test.js
```

`node:test` 53개. 날짜(윤년·말일 보정), 주기 경계, 학점 집계와 예상 부족, 긴급도 경계(30일·90일 정확히), 알림 기간 선택, ICS(CRLF, 75옥텟 접기, 다중 바이트 문자 보존, 쉼표·세미콜론·백슬래시 이스케이프, UID 유일성, VALARM 개수), CSV 이스케이프와 수식 주입 방지, 백업 왕복과 잘못된 입력 거부, AI 입력 최소화(자격명·기관·번호·메모 미포함), AI 응답 검증, 로컬 계획 합계 일치를 검사합니다. 네트워크 호출은 테스트에 없습니다.

## 데이터와 개인정보

- 모든 데이터는 **이 브라우저의 localStorage** 에만 저장됩니다 (키: `licensetrack-data`). 서버 전송과 계정이 없습니다.
- 손상된 저장 데이터는 지우지 않고 `licensetrack-data-corrupt` 키에 보관합니다.
- 달력(.ics) 파일에는 **자격 번호를 넣지 않습니다**. 자격명과 마감일, 필요 학점, 발급 기관만 들어갑니다.
- JSON 백업 파일에는 자격 번호와 메모가 **평문**으로 들어갑니다. 공용 기기에서 받지 마세요.
- 기기를 바꾸거나 브라우저 데이터를 지우면 데이터가 사라집니다. 정기적으로 백업하세요.

## AI 계획 (선택 기능)

- 본인의 Anthropic API 키를 직접 입력합니다. 키는 `licensetrack-ai-key` 로 localStorage에 저장되며, **브라우저 개발자도구에서 보입니다**. 공용 기기에서는 쓰지 마세요.
- 버튼을 눌렀을 때만 `https://api.anthropic.com/v1/messages` 로 요청을 보냅니다. 모델은 `claude-haiku-5-5`, `max_tokens` 는 700입니다.
- **보내는 것**: 익명 기호(A1, A2…), 남은 학점, 남은 개월 수, 분류 이름과 분류별 이수 학점 숫자.
- **보내지 않는 것**: 자격명, 발급 기관, 자격 번호, 메모, 과정명, 제공 기관, 날짜.
- 대상은 마감이 12개월 이내이고 남은 학점이 있는 항목 최대 8개입니다. 그 밖의 항목은 로컬 계획을 씁니다.
- 응답은 JSON만 받습니다. 항목 ID, 배열 길이(개월 수), 0 이상 숫자, 합계가 남은 학점과 같은지 검사하고, 통과하지 못한 항목은 로컬 계획으로 채웁니다.
- 키가 없거나 호출이 실패해도 로컬 계획(균등 또는 앞당김)은 똑같이 동작합니다.
- 키 형식 확인은 `sk-ant-` 접두어와 길이만 봅니다. 실제 유효성은 확인하지 않습니다.

## 수익화 메모 (구현하지 않음)

- 제안 가격: **일회성 9,900원** 안팎 (시장 조사 없이 정한 초안).
- 무료: 자격 3개까지, 기본 알림과 .ics, JSON 백업과 복원, 대시보드.
- 유료 후보: 자격 무제한, 학점 CSV와 요약 인쇄, AI 계획 (사용자 본인 키 기준이라 비용은 사용자가 부담).
- 결제 기능은 넣지 않았습니다. 필요하다면 별도 검토가 필요합니다.

## 한계와 미검증 항목

- **템플릿 값은 전부 미검증 예시입니다**: 간호사 3년·8시간, 공인중개사 2년·8시간, 안전관리자 2년·24시간, 사회복지사 3년·12시간, 세무·회계 CPE 1년·15시간, 건설기술인 5년·32시간, 위험물 안전관리자 2년·8시간. 실제 기준은 확인해야 합니다.
- 이월 학점의 한도와 인정 규칙은 계산하지 않습니다.
- 알림은 앱이 열려 있을 때만 브라우저 알림으로 나타납니다. 달력 알림의 실제 동작은 달력 앱마다 다릅니다.
- 주기 시작일은 만료일에서 역산합니다. 윤년 말일 근처 발급 건은 발급일과 하루 차이가 날 수 있습니다.
- 법률, 세무, 재무 자문이 아닙니다.
